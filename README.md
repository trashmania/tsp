## TSP(Tui Sigmo`s Power Manager) это менеджер электропитания, использующий tlp и powertop
Он умеет:
  - выводить информацию о общем потреблении в ваттах, температуре устройства, частоте цп и его загрузке
  - управлять профилями электропитания tlp(power-saver, balanced, performance, ac)
  - включать и выключать turbo boost
  - исполнять команду powertop --auto-tune для оптимизации tunables
## ⚠️ Предупреждение
Данная программа находится на этапе активной разработки, ставьте на свой страх и риск.

**На данный момент установочный скрипт поддерживается только на Arch Linux и его производных, не пробуйте на других дистрибутивах**

Установочный скрипт `install.sh` вносит следующие изменения в систему:
  - устанавливает `tlp`, `tlp-rdw`, `powertop`, `opendoas`, `go`
  - если находит, удаляет `power-profiles-daemon`, предварительно спрашивая пользователя
  - перезаписывает `/etc/tlp.conf`, если у вас есть свой конфиг обязательно сделайте бекап
  - добавляет `permit nopass <тебя> as root` в `/etc/doas.conf`, т.е. после установки вы сможете выполнять команды от рута без пароля с помощью doas, что и делает программа при вызове команд tlp и powertop
